## Constraints to preserve

- No runtime fullV/greedy/golden-output comparison found in the audited text/cohort/vendor paths. The smell is historical fixture membership and graph ordinals mixed into executable capability checks. Do not label every immutable code hash or ABI record as test data.
- `SourceNumericalContract::ReferenceCudaSm86Bf16V1` in `attention.rs:102-118`, actual QK dimensions/epsilon/rotary semantics, BF16 Head layouts1024/2048 and SM80/86 dispatch are real current math/kernel constraints. Keep the descriptor-to-executable agreement; unsupported operators/codecs/backend geometry must still refuse.
- Whole executable SHA/size/origin, complete formals, captured scalar words, pointer subextents, exact needed clear/copy policy remain required. Vendor ELF header exceptions (`cubin/elf.rs:110-137`, `elf/text_headers.rs:1-38`) accommodate actual pinned CUDA producer formats. They can later become a proper bounded format parser; do not just remove exceptions or admit arbitrary ELF versions.
- Retain Pool/OwnedCudaModuleSet on the original actor, one physical ResourceArbiter, actual retained source/image/lease owners, initialization/retirement flights, same service/generation checks, cancellation and quarantine. These are not fixture policy.

## Behavior-preserving migration interface

1. Move test-only scope SHA/export metadata and old matrix expectations to test support first. Separate neutral real native input payloads from fault-only construction states.
2. Introduce one private-issued immutable CUDA operator plan: actual typed source operator + math profile + matrix/state/row geometry -> pinned module/entry, complete ABI recipe, semantic binding roles, workspace/private/control requirements and conservative resource inventory. Source semantics stay in model/operator descriptors. No reference receipt, test case, prompt-list enum or model-size bool is an execution permit.
3. Initially compile the existing genuine packet bytes into that plan without changing any accepted behavior. Use actual plan coverage/keys to replace duplicate length and aggregate-count guards; unsupported shapes still lack an executable plan. Audit lookup failure before native allocation/admission.
4. Replace captured fixture addressing family by family with source-derived ABI builders, keyed by actual M/N/K/strides/attention controls and backend/kernel constraints. Existing packet matrix becomes qualification golden input, and independent original captures continue to test exact source/state/fullV behavior. Preserve every unused scalar byte unless actual source evidence proves a distinct valid construction.
5. Vendor consumes the sealed plan's exact image/formals/ABI and derived capacities on its existing actor/set, rather than model/five*eight policy. The trusted issuer must be non-forgeable; no generic runtime JSON manifest or user-asserted acceptance token.
