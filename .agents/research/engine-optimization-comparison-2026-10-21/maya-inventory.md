## Reading the inventory

- **Shipped**: implementation is present in inspected main; not a claim this researcher executed it.
- **Opt-in**: implementation present behind an explicit switch or bounded experimental selection.
- **Legacy**: actual older/inherited machinery exists; current GLM/DeepSeek default use is not assumed.
- **Claim**: performance/quality assertion from upstream release/docs; not independently reproduced.
- **E**: same declared arithmetic possible; requires exact source/state/physical proof.
- **F**: finite-precision arithmetic/profile can change. **D**: target distribution can be preserved with a different RNG stream. **A**: model/context/distribution changes.
- **LQ**: MAIN implemented with bounded accepted tests recorded in current plans. **LI**: isolated implementation/result. **LD**: design/open integration. **LU**: corresponding implementation/qualification not established by bounded source inspection. **NA**: architecture-specific and inapplicable to a model lacking that operation.
- These local statuses are per mechanism, not blanket feature parity. See [local anchors](#local-anchors); no test was executed by this research run.
